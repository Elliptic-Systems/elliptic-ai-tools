# Finding a skill's text

You can only vet what you can read. Menus change often, so these are general directions; if a menu has moved, search the product's own help pages.

## The easy way: drop in the file as-is
Attach the zip, .skill or .plugin file (or the SKILL.md) exactly as you received it. Attaching is better than copying and pasting: pasting can quietly strip out hidden characters, which are exactly what this check looks for.

## If the AI says it can't open the zip
1. Right-click the zip file and choose **Extract All**. Pick a new, empty folder, then click **Extract**. The new folder opens.
2. Click inside that folder and press **Ctrl+A** to select everything (on a Mac, Cmd+A). Open any sub-folders too, and select their files.
3. Drag the selected files into the chat.
4. Don't double-click or open any file ending in .py, .js, .sh, .ps1, .bat or .exe. Just drag them in with the rest, or tell the AI their names.

## Instructions someone shared with you as text
Copy the whole thing, including any notes at the very top or bottom, and paste it in.

## Someone else's custom GPT, Gem, Space or agent
Many platforms don't show you another person's instructions. If you can't read them:
- Judge the maker: who are they, can you contact them, is there a privacy policy?
- Judge what it can reach: does it list connected actions, apps or web access? Does it ask you to sign in to anything?
- Use it with fake data only until you trust the maker.
- The best this check can give is YELLOW.

## Skills from IR Brain, MyGentic or a marketplace
Download the actual file before you install it, then check it. Being listed in a marketplace doesn't mean it was security-reviewed.

## After every update
A skill that was GREEN last month can change. Re-run the check whenever the version changes or the maker announces an update.
